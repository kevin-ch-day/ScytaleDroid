# pi-writes

Resolve the approved audit account and shared intelligence schema from
SCYTALEDROID_AUDIT_DB_USER and SCYTALEDROID_AUDIT_PI_SCHEMA, or ignored local guidance.
Stop if missing. Verify CURRENT_USER and grants before inspecting data; reject
administrative accounts. Validate schema identifiers and redact authentication material.
Inspect actual columns before querying. Per write path report exact SQL, UTC time,
counts, latest timestamps and the provenance predicate: unknown dictionary/queue,
OEM seen metadata, signal catalog, governance snapshots and snapshot rows.
Cross-check producer labels against persistence/intelligence code and maintenance tools.
Separate proven attribution from unattributable totals. Classification/authority
provenance is not writer identity; encounter counters are not unique observations.
Keep specific results in the configured local report destination.
Never execute intake writers, import, copy, migrations or bootstrap during this audit.
